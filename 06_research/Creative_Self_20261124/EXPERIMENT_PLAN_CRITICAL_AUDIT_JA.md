# グループの実験計画の独立した科学的監査

対象：`inputs/Studienhandbuch_Thema4.pdf`（36頁、19.11.2026版）、`inputs/One-Page-Handout (A4).pdf`（03.12.2026中間発表案）。この資料はLLMが生成した仮案であり、掲載された引用、因果連鎖、評価ルーブリック、実施方法を先行研究が認めた科学的事実として扱わない。

## 1. 研究質問と概念上の弱点
| 優先度 | 位置 | 問題 | 推奨 |
|---|---|---|---|
| 最重要 | pp.4–5 | Creative Selfを課題中の自己表現・勇気・真正性・誇りの合算で作ろうとしているが、理論上の統一性がない | CSE/CPI、Perceived Expression、Ownership等を分離し主要アウトカムを事前選択 |
| 最重要 | pp.4–5 | AI評価→承認がない→努力が減る→自己が傷つく→創造性が下がる、という負方向を連ねる | 他の説明を競合仮説として設定。Jussupowの操作と今回の操作の差を明記 |
| 高 | p.4 | Goffmanを「AIは印象づけできない観客」と短絡的に使用 | 社会的存在・評価者についての信念の違いを実験仮説として扱う。Schultze & Brooks p.725は理論上の可能性 |
| 高 | p.5 | H4が主仮説なのに研究質問ではCreative Selfを中心とする | 主結果と副結果を事前に明示 |
| 高 | pp.24,31 | 事前General CSEと事後経験を比較し、Creative Selfの「低下」とする危険 | 事後の条件間差に限定。事前・事後の同一尺度でないなら変化量と呼ばない |
| 高 | pp.28,35 | 架空経歴を許しながら「本当の自分」を評価させる | 削除／別概念に修正。創作的表現と自己の真正さを混同しない |

## 2. 作品の創造性・志望動機課題
| 優先度 | 位置 | 問題 | 推奨 |
|---|---|---|---|
| 最重要 | pp.13–14 | Originalität + Überzeugungskraft + Persönlichkeitの等重み平均をCreative Scoreとする科学的根拠なし | Overall Creativityを別に採点。原著の概念に沿ったOriginalityとTask-Appropriatenessを分ける |
| 高 | p.13 | CATと固定ルーブリックを混同。4学生は創造性評価の専門家と自動的にみなせない | `CAT-inspired` と `rubric-based` を分け、評価者の適格性を説明 |
| 高 | pp.25–26 | 約200語20分で広告/応募背景読解と個性表現・部門選択・文章化を求める | パイロットで理解・多様な解決の産出・得点分布・時間制限を検証 |
| 高 | pp.25–26 | 文章力、ドイツ語能力、応募経験、企業への好みに結果が左右され得る | 測定目的と混入要因を特定し、適切な統制・限界を明記 |
| 中 | p.13 | 文法・誤字を「評価しない」と明記しても、評価者が無意識に影響される可能性 | 評価者・AIに共通の明確な指示を定め、感度分析を検討 |
| 中 | pp.16–17 | AIへの評価基準の与え方と人間評価のアンカーが完全に同じでも、同じ潜在構成概念を測っているとは限らない | 平均差だけでなく一致・分布・系統誤差を確認 |

## 3. 因果推論・統計・実施
| 優先度 | 位置 | 問題 | 推奨 |
|---|---|---|---|
| 最重要 | p.5, pp.18–19 | 媒介分析H5の識別仮定、事後測定とNに対する過剰な解釈 | 主解析は無作為群間の差。H5は当面探索的・説明仮説 |
| 高 | pp.5–6, 18–19 | `2×2`といっても参加者を4群に割り付けない。作品への実際の人間/AI採点は繰り返し測定 | 操作の因果効果と採点方法の差を峻別 |
| 高 | pp.10–11, 26,33 | AI vs 大学生という情報に専門性・公平性・共感等の期待差が含まれる | これは複合操作。一般の「AI vs 人間の真の効果」と広く解釈しない |
| 高 | pp.26,33 | Q2.2–2.4が創作前に承認、独創性の見返りを強調する | 質問自体によるプライミングを検討。最小化／時点変更も候補 |
| 高 | p.19 | Q2.1誤答、Q4.10不正解、50語未満を主解析で除外 | 無作為割付後の選別によるバイアスを検討。感度分析と割付ベースの解析を区別 |
| 高 | p.18 | N80–100で多くの仮説、交互作用と複数媒介を検定 | 主要結果の検出力を先に計算。効果量、CI、探索的な位置づけ |
| 高 | pp.14,16–17 | AI2モデル×3回は6人の独立評価者を意味しない | モデルと反復を階層的に記録、評価者・モデル別に比較 |
| 中 | p.6 | コース内ブロック無作為化は良いが同席者間で情報が漏れる可能性 | クラス/学校ID・配布順・contaminationを記録 |
| 中 | p.18 | `Cronbach α ≥0.70`だけで尺度が妥当とは言えない | 項目内容、一次元性、信頼性、改変尺度の性質を検証 |
| 中 | p.28 | Q4.19–4.21のAI評価観を創作後に測り、処置前からのModeratorとする | 事前特性と事後の認識を区別。処置後の共変量で交絡を作らない |
| 中 | p.18 vs 参加者用p.29/36 | `5.7`がコードブックで「研究目的の推測」、参加者用紙では学校AI利用頻度。研究目的推測は`5.8` | データ辞書を修正（具体的な参照ミス） |

## 4. 実施・倫理・研究文化
| 優先度 | 位置 | 問題 | 推奨 |
|---|---|---|---|
| 最重要 | pp.10–12,19–20 | 未成年、高校授業内、部分開示、API送信という複合リスク | 大学担当窓口、学校・州の許可、同意/撤回、サービス契約・プライバシーを事前確認 |
| 高 | pp.10–12 | 賞金3×25€の選抜に、AI採点/人間採点/説得力/総合創造性のどれを使うかが不明 | 事前選考基準と参加者向け説明を一致 |
| 高 | pp.24,31 | 母親の名前の2,3文字と誕生日による参加コードは匿名性に疑問、重複もあり得る | 無作為IDと別の撤回トークン |
| 中 | pp.8,12 | Debriefingが数週間後、教師を介しての撤回 | 期限・連絡方法・未受領者・匿名化との関係を設計 |
| 中 | pp.8–9 | 5–10人のpretestは手順確認には有益だが尺度検証には不足 | パイロットで確認できる範囲を限定して記載 |
| 中 | Handout p.1 | EU AI Actの一律の高リスク法的分類の説明 | 高リスク指定の用途・適用日・研究利用の条件を別途法令で検証。断定しない |

## 5. 採用・保留・拒否
- **維持検討**：AI/人間評価者の予期を個人無作為化、応募文を同条件で書かせ、割付ブラインドで独立採点。実際の人間/AI評価は各作品の評価方法比較に利用。
- **修正して採用**：応募文課題（目的・独創性・適切性の理論化とパイロット要）、General CSE（原尺度からの翻訳妥当性）、Creative Selfの課題固有の指標（定義・測定を再構築）。
- **いったん採用しない**：H1–H5の単一負方向連鎖、無根拠な三次元等重み平均、`Cronbach α`のみで妥当化、事後除外の主解析、AI採点を「真の創造性」とする扱い。
