# 更新時の納品契約

**必須納品**：最新版ZIP、変更対象章の日本語Markdown全文、ドイツ語Markdown全文、更新版HANDOFF_CURRENT.md、変更履歴、議題と後続章用の論点、文献の原文根拠カード（必要なとき）。

1. 着手前：最新ZIPと原著・公式テンプレートを確認し、既に回答された質問を再質問しない。
2. 根拠：各実証的主張にL-ID/EV-IDを付ける。原文・ページを保管。未確認資料は事実扱いしない。
3. 生成した章内の日本語・ドイツ語は議論用の**草稿・アウトライン・推敲候補**。テンプレートに従い、そのまま提出原稿へ転記不可。
4. 版：新規vNNNを作って旧版は保持。ファイル名と見出しに版・日付・状態を入れる。
5. 章：変更箇所だけでなく**章全体の最新版**を両言語で保存。すべての章が常に存在する状態にする。
6. 引継ぎ：議題、決定と根拠、未決事項、後続章へのフラグを必ず最新化する。
7. 最後に: `tools/validate_system.py`で検証。ZIPにすべての原著PDFを含む。
